
# Week 4 - Python Performance Optimization

## Project Overview

This project demonstrates how to identify performance
bottlenecks and optimize a Python application.

The application processes student marks and calculates
student counts, subject totals, averages, and pass counts.

## Technologies Used

- Python
- Visual Studio Code
- timeit
- cProfile
- unittest

## Project Files

- baseline.py: Original implementation
- optimized.py: Optimized implementation
- benchmark.py: Benchmarking and profiling program
- test_performance.py: Automated tests
- reports/: Performance report
- results/: Benchmark and profiling outputs

## How to Run

Run the benchmark:

python benchmark.py

Run automated tests:

python -m unittest -v

## Optimization Techniques

1. Replaced list-based membership checks with a set.
2. Used defaultdict for aggregation.
3. Processed records in one aggregation pass.
4. Eliminated repeated calculations.

## Results

The benchmark script measures the runtime of both
implementations and calculates the speedup and runtime
reduction. See reports/performance_report.md.

## Dependencies

Python 3.9 or newer is recommended.
No third-party packages are required.
All test data is generated by the application.
